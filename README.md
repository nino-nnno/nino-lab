# nino编程实验室

面向少儿编程启蒙的课程与工作室网站，包含机器人、Scratch、Python 和 C++ 学习路线，以及试听说明和课程详情页。

## 在线访问

[打开 nino编程实验室](https://nino-nnno.github.io/nino-lab/)

## 页面结构

- `portfolio/seedlab.html`：工作室主页
- `portfolio/seedlab-trial.html`：免费试听说明与预约信息整理
- `portfolio/seedlab-course-*.html`：各课程详情
- `index.html`：GitHub Pages 总入口

网站为静态 HTML/CSS/JavaScript，可直接通过 GitHub Pages 发布。
